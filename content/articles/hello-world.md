Every article is a Markdown file in `content/articles/`. Its file name is its
address: this file is `hello-world.md`, so it lives at `/blog/hello-world`.
Once an article is published, never rename its file.

## The front matter

The lines between the two `---` at the top describe the article: its title,
a description of about 140 to 160 characters, the date it was published and
its author. Add `updated: "YYYY-MM-DD"` when you change it in a way readers
should know about.

## The body

The template shows the title as the page's main heading, so the body starts
at level two. Tables, lists, links and code all work:

| You write | Readers see    |
| --------- | -------------- |
| Markdown  | A clean page   |
| Dates     | Dates, and the same dates in search |

Raw HTML in an article is dropped rather than shown.
